# 🕹️ Tic-Tac-Toe Game in React
Created with CodeSandbox

This is a simple, interactive **Tic-Tac-Toe** game built using **React** to help reinforce core React concepts such as state management, props, and component-based design.

## 🚀 Features

- ✅ Play classic Tic-Tac-Toe (X vs O)
- 🏆 Displays the winner once the game ends
- 📜 Keeps a history of all moves
- ⏪ Allows players to **review** and **revisit** previous moves
- ⚛️ Built to practice and showcase React fundamentals

## 🛠️ Technologies Used

- **React**
- **JavaScript**
- **CSS**

## 🧩 How It Works

- The game board updates in real-time as players take turns.
- Once a player wins or the game ends in a draw, a message appears.
- Every move is stored in a history array.
- You can jump back to any previous move and "time travel" through the game!
